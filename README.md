# Duo – site public

Site de présentation de [Duo](https://duo-app.app/), l'app iPhone pour la vie à deux.

- `index.html` : page d'accueil
- `aide.html` : aide et contact (URL d'assistance App Store)
- `confidentialite.html` : politique de confidentialité (URL exigée par l'App Store)
- `tools/build_pages.py` : régénère les deux pages (`python3 tools/build_pages.py`)

Publié avec GitHub Pages sur https://duo-app.app (fichier CNAME).
